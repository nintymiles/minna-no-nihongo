# コモンズの悲劇

　「コモンズの悲劇」という有名な言葉がある。この言葉は地球の環境と人間活動を考える上でとても重要な意味をもつようになってきた。話は村の共有地に始まる。共有地には牧草があり、誰でもそこで羊を飼うことができる。人々はできるだけ多くの羊をそこに入れ、自分の利益を少しでもあげることを試み始めた。このような競争の結果、牧草地は荒廃してしまい、誰も羊を飼うためには利用できなくなり、その共有地は捨て去られてしまった。イソップ物語にでも出てきそうな事柄であるが、1968年に投稿され、アメリカの『Science』誌に出た有名な論文に基づいた話である。

　ここで大事なことは、このような競争がなぜ始まったかということである。恐らくこの共有地はそれまで大事にされ、いろいろなやり方で地域の人々によって守られてきていたに違いない。あるいは過去にもそのような失敗があり、これに懲りた人々がそれを守る仕組みや掟を伝統的な文化の中に組み込んでおいた可能性もある。なぜこの物語が有名になり、いろいろな識者によって語られるようになったのであろうか。それは現在の地域や地球規模の環境問題の多くがこの牧草地のあり方の問題に直結しているからである。牧草地を普遍化すると公共圏（コモンズ）といわれる。それは、身近には水資源であり、山林、河川、湖である。地球規模で考えるならば、大気であり、その中の酸素であり、少々ものを捨ててもだれにも文句をいわれない海洋である。それらを皆が自分の利益のためだけに使ったら、全部がだめになってしまうということを、コモンズの悲劇は意味している。

　異なる文化はさまざまな神話をもち、それぞれ異なる政治的および道徳的な信念を支えにしている。それがそれぞれの地のコモンズを支えてきた。このため、自然科学と社会科学に人文科学の研究を織りまぜなければ、環境か開発かのジレンマを掘り下げることはできない。これから地球環境を制御するシステムの理解が深まるにつれて、無数の相互作用や可能性のある解決策が見えてくるであろう。

　人間が農耕を開始して1万年間いろいろな失敗をし、教訓を得てきている。メソポタミアの灌漑による土壌への塩類集積、アラル海の縮小、海浜の消失等々数えあげればきりがないであろう。しかしこれからの環境問題は全地球的に及んでおり、一度失敗するとあとのつけは数百年に及ぶ可能性があり、失敗から教訓を学ぶようなやり方はとれなくなっているのである。コモンズの悲劇の最も大事な教訓はここにある。このためには結果を予測し、いろいろな起こり得る事象を明確にし、その確率を明らかにしておくことが不可欠となる。　　　　　

　　　　　　　　　　　　　（和田英太郎　『環境学入門3　地球生態学』岩波書店より)



## P0

コモンズの悲劇　訳

这是日语词汇，中文翻译为‌**共有地的悲剧**‌，也可直接译为公地悲剧，是经济学中的经典概念。

### 概念含义

该概念由美国生态学者加勒特·哈丁于1968年在《科学》期刊发表论文提出，描述的是：当资源为所有人自由共享时，每个个体为了追求自身利益最大化，会无节制地过度使用资源，最终导致资源枯竭、全部使用者共同受损的结果，也可以引申理解为“个人追求利益的理性行为，最终会导致集体利益受损”，也被称作“社会困境”。

### 经典案例

最典型的例子就是‌**公共牧场放牧**‌：一块所有人都可以自由使用的公共牧草地，每个农民都会想要多放一头牛来增加自己的收益，如果只放牧自己的私人土地，农民会主动控制牛的数量保护草场；但在公共牧地上，农民会担心“我不增加牛，别人也会增加，我的收益反而会变少”，于是所有人都持续增加放牧数量，最终导致草场被彻底破坏、所有农民都无法再获得收益，最终集体受损。

### 文法结构分析

这是典型的「‌**名词1+の+名词2**‌」结构，在日语语法中：

- 「の」作为格助词，在这里连接两个名词，表示所属关系，含义为“共有地的悲剧”
- 整个短语是偏正结构，核心名词为「悲劇（ひげき）」，前面的「コモンズの」是定语修饰限定后面的核心名词，说明是“什么的悲剧”。

该短语是经济学/社会学概念，原词来自英文「the tragedy of the commons」，日语转写为「コモンズの悲劇」，对应中文通用译法为‌**公地悲剧/共有地悲剧**‌。

### 二、核心文型拆解

1. ‌**～を考える上で**‌
   含义：“在思考……的层面上/在探讨……的过程中”，是社科说明文表限定场景的经典书面句型。
2. ‌**～に始まる**‌
   含义：“始于……”，用于交代事件、故事的起源，叙事逻辑清晰严谨。
3. ‌**～ことができる**‌
   含义：“能够……/可以……”，表公共资源的开放属性，客观说明规则特征。
4. ‌**～ようになってきた**‌
   含义：“逐渐变得……”，体现语义上的动态变化过程，贴合科普文本的递进叙事逻辑。
5. ‌**～に基づいた**‌
   含义：“基于……的”，用于补充内容的学术出处，强化文本的严谨性，是学术科普类文本的高频句型。
6. ‌**～てしまう**‌
   含义：表动作最终走向不可逆的负面结果，精准对应“草场彻底荒废”这类悲剧性结局的语义。
7. ‌**～そうな事柄であるが**‌
   含义：“看似是……的事物，但实际上……”，通过转折衔接通俗叙事与学术背景，兼顾可读性与专业性。

结合你之前提供的「公地悲剧」社科说明文文本背景，下面为你逐点详细拆解这些核心语法点的接续规则、语义差异和文本中的实际用法：

### 一、～を考える上で

1. ‌**接续规则**‌：动词辞书形 / 名词 + を考える上で
2. ‌**核心语义**‌：限定动作的适用场景，表“在探讨、考量某件事的过程中”，是社科类书面文本的高频限定句型，区别于口语化的「～する時」，自带严谨的学术属性。
3. ‌**原文用法**‌：「地球の環境と人間活動を考える上で」，精准点明后续内容的讨论前提，让科普文本的逻辑边界更清晰。

### 二、～ようになってきた

1. ‌**接续规则**‌：动词辞书形 / 可能形 + ようになってきた
2. ‌**核心语义**‌：体现从过去到现在逐步发生的、不可逆的动态变化，区别于单纯表过去动作的「～なった」，暗含“趋势持续推进”的递进语感。
3. ‌**原文用法**‌：「重要な意味をもつようになってきた」，说明“公地悲剧”的重要性是随环境问题加剧逐步提升的，而非一开始就具备高关注度。

### 三、～に基づいた

1. ‌**接续规则**‌：名词 + に基づいた
2. ‌**核心语义**‌：表内容、结论的权威依据，明确标注信息的来源，是学术类文本强化严谨性的标志性句型，区别于普通表原因的「～から」，突出内容的事实支撑属性。
3. ‌**原文用法**‌：『Science』誌に出た有名な論文に基づいた話，直接点明故事的学术出处，避免读者将其误判为普通寓言故事。

### 四、～てしまう

1. ‌**接续规则**‌：动词て形 + しまう
2. ‌**核心语义**‌：包含两层核心含义，一是动作彻底完成，二是伴随出现不可逆的负面结果，带有遗憾、惋惜的情绪倾向，是叙事类文本烘托悲剧性结局的常用句型。
3. ‌**原文用法**‌：「牧草地は荒廃してしまい」「共有地は捨て去られてしまった」，精准烘托出公地被彻底破坏、无法挽回的悲剧结局，强化“公地悲剧”的核心警示意味。

### 五、～ことができる

1. ‌**接续规则**‌：动词辞书形 + ことができる
2. ‌**核心语义**‌：书面语中表“具备做某事的能力/权限/可能性”，区别于口语化的动词可能形，在正式说明文、学术文本中使用频率更高，语气更客观中立。
3. ‌**原文用法**‌：「誰でもそこで羊を飼うことができる」，客观说明公共牧场的开放属性，不带任何主观情绪，符合社科文本的中立叙事要求。

### 六、～に始まる

1. ‌**接续规则**‌：名词 + に始まる
2. ‌**核心语义**‌：追溯事件、理论、故事的起源起点，表“始于……”，是科普文本梳理脉络的经典句型，比普通的「～から始まる」更具书面正式感。
3. ‌**原文用法**‌：「話は村の共有地に始まる」，清晰点明整个“公地悲剧”故事的叙事起点，让读者快速进入场景。

### 七、～そうな～であるが

1. ‌**接续规则**‌：动词连用形/い形容词词干/な形容词词干 + そうな + 名词 + であるが
2. ‌**核心语义**‌：通过委婉转折，先给出大众的表层印象，再引出事物的真实本质，兼顾科普文本的通俗性与专业性，避免生硬的学术说教。
3. ‌**原文用法**‌：「イソップ物語にでも出てきそうな事柄であるが」，先引导读者产生“这是一则寓言”的直观感受，再转折引出它的学术论文出处，形成认知反差，强化读者记忆点。

## 全文通顺中文翻译

在这里，重要的是：为什么这样的竞争会开始。恐怕这片共有地在那之前一直被珍视着，被当地人们以各种方式守护着。或者，过去也曾有过类似的失败，吸取了教训的人们将守护它的机制和规矩编入了传统文化之中。为什么这个故事变得有名，被各种有识之士所谈论呢？那是因为当今许多地区性和全球性的环境问题，都与这片牧草地的存在方式直接相关。将牧草地普遍化，就被称为"公共圈"（Commons，公地）。在身边来说，它是水资源、山林、河流、湖泊。从地球规模来想的话，它是大气、其中的氧气、以及即使丢弃少许东西也不会被任何人抱怨的海洋。如果大家都仅仅为了自己的利益而使用这些资源，那么一切都将变得完蛋——"公地的悲剧"正是意味着这件事。
