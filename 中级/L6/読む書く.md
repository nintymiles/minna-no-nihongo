## メンタルトレーニング

​	ある有名な作家がこんなことを言っていました。

​	「昔、東京に出てきたばかりのころ、自分の将来が不安になるとよくアパートの部屋で記者会見ごっこをやりました。成功した自分と雑誌の記者を一人でやるのです。『小説か売れないころはどのように過ごしていたのですか』『そのころ、何を考えていましたか』

​	『今、どんな気持ちですか』……。自分にそんな質問をして、それに有名作家になったつもりで答えるんです。『キャベツばかり食べていたけど気持ちは全然暗くなかった』とか、『世の中がアホに見えていました』とか。一人で質問をしたり、答えたりしていると、不思議と迷いはなくなるんです。自分の将来の夢が具体的に見えてくるんです。」

​	最近、いろいろなところで開かれているビジネスマンのためのメンタルトレーニングでも、これと同じようなことを行います。静かに目を閉じて、将来なりたいと思う自分をイメージし、自分がそれになったつもりで、そこから今の自分を見るというトレーニングです。下の図を見てください。頭の中に具体的に理想の自分がイメージできたら、立っている位置を変えて、今の、つまりイメージの中では過去の自分と向き合うのです。そうすれば、将来の理想の自分から見て、現在の自分に何が足りないのか、何をしなければならないかがわかってきます。

​	そこから、問題をどのように解決するか考え、プランを立ててチャレンジしてみるのです。失敗したら、もう一度チャレンジする。そうすれば、あなたの夢や理想はだんだん近づいてくるでしょう。

(木村孝．藤田完二．高橋慶治『ビジネスマン・成功の条件心と脳を強くするメンタル・トレーニング』PHP研究所より、一部を改変して掲載)

### T1

“メンタルトレーニング” 的中文翻译是：

‌**心理训练**‌

或者更具体一点：

‌**心理素质训练 / 心智训练**‌

**解释说明：**

- ‌**メンタル**‌ 源自英语 “Mental”，意思是“精神的”、“心理的”、“心智的”。
- ‌**トレーニング**‌ 源自英语 “Training”，意思是“训练”、“练习”。

所以结合起来的 ‌**メンタルトレーニング**‌ 指的是：

- 旨在提升心理韧性、专注力、自信心、压力管理能力、情绪控制能力等心理素质的训练方法。
- 广泛应用于体育运动、商务职场、艺术表演、教育学习、压力管理以及日常生活等各个领域，帮助人们在高压或挑战性情境下保持最佳心理状态、发挥最佳表现。

因此，“‌**心理训练**‌” 是最常用和贴切的翻译。

对句子「ある有名な作家がこんなことを言っていました。」进行详细的逐词翻译、平假名标注和文型分析。

‌**分析句子：ある有名な作家がこんなことを言っていました。**‌

‌**1. 逐词翻译 (Word-by-Word Translation):**‌

| 日本語 | 品詞 (Part of Speech)        | 意味 (Meaning)  | 備考 (Notes)                                      |
| ------ | ---------------------------- | --------------- | ------------------------------------------------- |
| ある   | 連体詞 (Pre-noun adjectival) | 某个，一个      | 修饰名词，表示不确定的“某一个”                    |
| 有名な | 形容動詞 (Na-adjective)      | 有名的，著名的  | ‌**★ 連体形 (Attributive form)**‌, 修饰名词「作家」 |
| 作家   | 名詞 (Noun)                  | 作家            |                                                   |
| が     | 格助詞 (Case particle)       | [主语标记]      | 提示主语「ある有名な作家」                        |
| こんな | 連体詞 (Pre-noun adjectival) | 这样的，这种的  | 修饰名词「こと」                                  |
| こと   | 名詞 (Noun)                  | 事情，话，内容  |                                                   |
| を     | 格助詞 (Case particle)       | [宾语标记]      | 提示宾语「こんなこと」                            |
| 言って | 動詞 (Verb)                  | 说 (say)        | 「言う」的て形 (Te-form)                          |
| い     | 補助動詞 (Auxiliary verb)    | [持续/状态标记] | 「いる」的词干                                    |
| ました | 助動詞 (Auxiliary verb)      | [礼貌体过去时]  | 「ます」的过去形                                  |
| 。     | 句点 (Period)                | 句号            |                                                   |

‌**2. 平假名标注 (Hiragana Reading / Furigana):**‌

- ‌**ある有名な作家がこんなことを言っていました。**‌
- ‌**ある ゆうめいな さっかが こんな ことを いって いました。**‌

‌**3. 文型 (Sentence Pattern / Grammar Structure):**‌

这个句子的核心结构和关键文型如下：

1. ‌**主语部分 (Subject Phrase): `[連体詞] + [形容動詞連体形] + [名詞] + が`**‌
   - ‌**ある**‌ (连体词) + ‌**有名な**‌ (形容动词连体形) + ‌**作家**‌ (名词) + ‌**が**‌ (主格助词)
   - ‌**功能：**‌ 明确句子的主语是谁。`が` 标记了动作「言う」的发出者。
   - ‌**含义：**‌ “某个有名的作家”
2. ‌**宾语部分 (Object Phrase): `[連体詞] + [名詞] + を`**‌
   - ‌**こんな**‌ (连体词) + ‌**こと**‌ (名词) + ‌**を**‌ (宾格助词)
   - ‌**功能：**‌ 明确动作「言う」的对象是什么。`を` 标记了被说的内容。
   - ‌**含义：**‌ “这样的话（事情/内容）”
3. ‌**谓语部分 (Predicate): `[動詞て形] + いる (の過去・丁寧形)`**‌
   - ‌**言って**‌ (「言う」的て形) + ‌**い**‌ (「いる」的词干) + ‌**ました**‌ (「ます」的过去形)
   - ‌**功能：**‌ 构成句子的谓语核心，描述主语的动作及其状态和时态。
   - ‌关键文型: `～ている`
     - ‌**形式：**‌ 动词て形 + いる
     - ‌**用法：**‌ 这里表示 ‌**动作结果的存续状态**‌ 或 ‌**经验/记录**‌。表示“说过”这个动作已经完成，并且其内容（“这样的话”）作为一种信息或事实存在于说话者的认知或记录中。这是日语中描述“某人说过...”或“有记载说...”时非常自然和常见的表达。
     - ‌**时态与礼貌：**‌ `いました` 是 `ている` 的 ‌**过去、礼貌形式**‌ (`ている` -> `ています` -> `ていました`)。表示这个“说过”的动作/状态发生在过去，并且整句话是用礼貌体表达。

‌**总结句意 (Overall Meaning):**‌
“某个有名的作家说过这样的话。”

‌**关键语法点总结 (Key Grammar Points):**‌

- ‌**连体词 (`ある`, `こんな`):**‌ 直接修饰后续名词。
- ‌**形容动词修饰名词 (`有名な + 作家`):**‌ 形容动词修饰名词时用‌**连体形 `～な`**‌。
- ‌**格助词 `が`:**‌ 标记‌**主语**‌。
- ‌**格助词 `を`:**‌ 标记‌**直接宾语**‌。
- ‌**て形 + いる (`～ている`):**‌ 表示‌**动作结果的存续**‌或‌**经验/记录**‌。在本句中表示“说过（并且其内容作为信息存在）”。
- ‌**礼貌过去时 (`～ました`):**‌ `言っています` (现在礼貌形，表示状态持续) -> `言っていました` (过去礼貌形，表示过去的状态或完成的动作)。

‌**后续可补充内容:**‌
这个句子本身是一个引子。它告诉我们“有个著名作家说过某句话”，但还没有告诉我们具体说了什么。如果你有这位作家说的具体内容（比如「人生は...」），可以将其放在「こんなこと」的位置，或者用「と」来直接引用：`...が「（具体内容）」と言っていました。` 我们可以进一步分析引号内的具体内容。

‌**文型解析**‌

‌**1. 並列賓語結構**‌

```
[A]と[B]を
```

- ‌**構成**‌：成功した自分（A）＋ と（並列）＋ 雑誌の記者（B）＋ を（賓語）
- ‌**功能**‌：將兩個角色並列為動作「やる」的共同對象
- ‌**直譯**‌：*扮演「成功的自己」和「雜誌記者」兩個角色*

‌**2. 方式狀語結構**‌

```
一人で + [動作]
```

- ‌**構成**‌：一人（獨自）＋ で（方式格助詞）＋ やる（動作）
- ‌**功能**‌：強調「以單獨一人」的方式完成動作
- ‌**直譯**‌：*獨自一人完成（扮演）*

‌**3. 說明性判斷句式**‌

```
～の です
```

- ‌**構成**‌：やる（動詞）＋ の（名詞化）＋ です（斷定）
- ‌**功能**‌：對前述行為進行解釋說明（含強調語氣）
- ‌**直譯**‌：*「是要...」 / 「指的是...」*

------

‌**整體翻譯**‌

‌**「（我）獨自一人分饰兩角——扮演成功的自己與雜誌記者。」**‌

------

‌**翻譯要點解析**‌

1. ‌**並列角色處理**‌
   - 日語「AとBを」結構 → 中文「A與B兩角」
   - 增譯「分饰兩角」明確角色扮演的實質（原文隱含）
2. ‌**一人で的戲劇性反差**‌
   - 直譯「獨自一人」保留孤獨感
   - 通過破折號強調「一人扮演雙重身份」的矛盾張力
3. ‌**語境還原**‌
   - 「成功した自分」譯為「成功的自己」而非「成功人士」，保留自指性
   - 「やる」譯為「扮演」呼應前文「記者会見ごっこ」的遊戲性質

------

‌**語法深解**‌

| 關鍵表達       | 意義剖析                                   | 例句擴展                     |
| -------------- | ------------------------------------------ | ---------------------------- |
| ‌**と（並列）**‌ | 列舉完全對等項                             | 猫‌**と**‌犬を飼う（養貓和狗） |
| ‌**で（方式）**‌ | 表動作狀態/手段                            | 箸‌**で**‌食べる（用筷子吃）   |

‌**整体翻译**‌

------

‌**翻译要點解析**‌

1. ‌**心理学术语处理**‌
   - ‌**イメージし**‌ 译为 ‌**"想象"**‌ → 但实际是心理学「意象训练（imagery training）」的技法
   - ‌**トレーニング**‌ 译为 ‌**"训练"**‌ 而非"练习"，强调系统性方法
2. ‌**时空视角转换**‌
   - ‌**そこ**‌（虚拟未来位置）译为 ‌**"彼处"**‌ 保留空间隐喻
   - ‌**今の自分**‌ 译为 ‌**"当下的自我"**‌ 突显与未来自我的对立
3. ‌**つもりで的深度翻译**‌
   - 不直译"假装"，用 ‌**"化身为...的心态"**‌ 体现意识主动转换
   - 增译 ‌**"立场"**‌ 明确「から」的观察点属性

1. ‌条件从句：

   ```
   今の、つまりイメージの中では過去の自分と向き合うのです
   ```

   - ‌核心结构:

     ```
     [对象] と [动词] のです
     ```

     - `のです` 用于解释原因、说明情况或加强语气，这里强调这个动作是整个方法的目的或本质。

10. ‌プランを (puran wo):

    - `プラン (puran)`: 计划 (外来语，plan)
    - `を (wo/o)`: (宾格助词)

11. ‌**立てて (たてて - tatete):**‌ 制定，建立 (动词`立てる`的て形)

12. ‌チャレンジして (charenji shite):

    - `チャレンジ (charenji)`: 挑战，尝试 (外来语，challenge， 名词/サ变动词词干)
    - `して (shite)`: (动词`する`的て形)
    - *合起来：* ‌**挑战，尝试**‌ (这里更侧重“尝试去做”)

13. ‌みる (miru):

    ‌ 看，试试看 (动词

    ```
    みる
    ```

    的原形，作为补助动词接在て形后)

    - *合起来 (チャレンジしてみる):* ‌**尝试挑战/试着去做**‌ (`てみる`表示尝试做某事)

14. ‌**の (no):**‌ (形式名词，使前面的动词短语名词化)

15. ‌です (desu):

    ‌ (判断助动词，表示断定、说明，礼貌体)

    - *合起来 (...してみるのです):* ‌**（我们）是要...尝试去做的**‌ (解释说明情况或理由，加强语气)

‌**全句直译：**‌
由此出发，（我们）要考虑如何解决问题，制定计划，并尝试去挑战（实践）。

‌**更自然的意译：**‌
接着，就要思考如何解决这些问题，制定计划，并付诸实践去尝试。

‌**文型分析 (句型分析)：**‌

1. ‌起点状语：

   ```
   そこから
   ```

   - ‌**功能：**‌ 明确指出本句动作的起点是承接前文的结果（即明白了不足和必须做的事），相当于“基于此”、“接下来”。

2. ‌宾语从句：

   ```
   問題をどのように解決するか
   ```

   - ‌**结构：**‌ `[宾语] を + [疑问词] ように + [动词] + か`
   - ‌**功能：**‌ 作为一个整体名词性成分（疑问从句），作后续动词`考え`（思考）的‌**宾语**‌。意思是“思考 ‌**如何解决问题**‌ 这件事”。

3. ‌一连串的动作（动词て形连接）：

   ```
   考え、プランを立ててチャレンジしてみる
   ```

   - ‌结构分析：

     - `考え`： 动词`考える`的‌**て形中顿**‌。它连接后续动作，表示“思考”是后续动作的前提或并列动作。
     - `、`： 逗号分隔并列的动作成分。
     - `プランを立てて`： 动词`立てる`的‌**て形**‌。`プランを`是其宾语。这个て形连接后续动作`チャレンジして`。
     - `チャレンジしてみる`： `チャレンジする`的‌**て形 + みる**‌。`みる`作为补助动词，表示“尝试做...”。

   - ‌功能：

     ‌ 这一串用て形（包括中顿和て形）连接的动词短语，描述了‌

     连续或并行的几个步骤：

     1. 思考如何解决问题 (`問題をどのように解決するか考え`)
     2. 制定计划 (`プランを立てて`)
     3. ‌**并**‌ 尝试去实践/挑战 (`チャレンジしてみる`)

   - ‌关键点：

     - `考え`用的是‌**中顿形**‌，它本身可以连接后续句子成分，这里清晰地并列了三个主要动作环节。
     - `立てて`和`チャレンジして`是标准的‌**て形**‌，表示动作的连续或方式。
     - `てみる` 为最后一环的动作`チャレンジする`增添了‌**尝试性**‌。

4. ‌句末说明与强调：

   ```
   ...みるのです
   ```

   - ‌**结构：**‌ `动词原形 + の + です`
   - ‌功能：
     - `の` 将前面一整串动作 (`考え、プランを立ててチャレンジしてみる`) ‌**名词化**‌。
     - `です` 对这个名词化的动作流程进行‌**断定、说明或解释**‌。这里带有解释“这就是要做的事情”或“情况就是这样”的语气，使表达更完整、更有力，也呼应了前文逻辑（因为明白了不足，所以接下来自然要做这些事）。

‌**总结句型流程：**‌

1. ‌**起点：**‌ 基于前文的结果 (`そこから`)...
2. ‌核心动作链：
   - ‌**思考：**‌ ...思考如何解决问题 (`問題をどのように解決するか考え`)...
   - ‌**制定：**‌ ...（并）制定计划 (`プランを立てて`)...
   - ‌**尝试行动：**‌ ...（并）尝试去挑战/实践 (`チャレンジしてみる`)。
3. ‌**说明强调：**‌ ...（这）就是（我们要）做的 (`のです`)。

‌**核心文型亮点：**‌

- ‌**疑问词+か 作宾语：**‌ `どのように解決するか` 作为`考え`的宾语。
- ‌**动词て形（中顿）连接并列动作：**‌ `考え、...立てて...してみる` 清晰地列出连续的步骤。
- ‌**～てみる：**‌ 表示尝试做某事。
- ‌**～のです：**‌ 用于说明情况、解释原因或加强语气。

这个句子完整地描述了从认知（发现问题）到行动（思考方案、制定计划、付诸实践）的闭环过程，是个人成长或解决问题方法论中的关键一步。`てみる`体现了行动中的探索精神，`のです`则加强了整个行动过程的必然性和说明性。

#### S2、３

**日语句子：**‌
失敗したら、もう一度チャレンジする。 そうすれば、あなたの夢や理想はだんだん近づいてくるでしょう。

‌**逐词翻译与平假名标注 (分句分析)：**‌

‌**第一短句：失敗したら、もう一度チャレンジする。**‌

1. ‌失敗したら (しっぱい したら - shippai shitara):
   - `失敗 (しっぱい - shippai)`: 失败 (名词/サ变动词词干)
   - `したら (shitara)`: (动词`する`的‌**たら形**‌)
   - *合起来：* ‌**如果失败了/失败的时候**‌ (`たら` 表示‌**条件**‌，“如果...的话”或“...的时候”)
2. ‌**、 (、):**‌ 逗号
3. ‌もう一度 (もう いちど - mou ichido):
   - `もう (mou)`: 再，又一次 (副词)
   - `一度 (いちど - ichido)`: 一次 (名词)
   - *合起来：* ‌**再一次**‌
4. ‌チャレンジする (charenji suru):
   - `チャレンジ (charenji)`: 挑战，尝试 (外来语，challenge， 名词/サ变动词词干)
   - `する (suru)`: 做 (サ变动词)
   - *合起来：* ‌**挑战，尝试**‌ (这里指“再次尝试/挑战”)
5. ‌**。 (。):**‌ 句号 (结束第一个短句)

‌**第一短句直译：**‌ 如果失败了，就再次挑战。

‌**第二短句：そうすれば、あなたの夢や理想はだんだん近づいてくるでしょう。**‌

1. ‌そうすれば (sou sureba):

   - `そう (sou)`: 那样 (副词，指代前一句描述的行为“失敗したら、もう一度チャレンジする”)
   - `すれば (sureba)`: (动词`する`的‌**ば形**‌)
   - *合起来：* ‌**如果那样做的话/那样做的话**‌ (`ば` 表示‌**条件**‌，承接前文)

2. ‌**、 (、):**‌ 逗号

3. ‌あなたの (anata no):

   - `あなた (anata)`: 你
   - `の (no)`: (所有格助词)
   - *合起来：* ‌**你的**‌

4. ‌**夢 (ゆめ - yume):**‌ 梦想

5. ‌**や (ya):**‌ (并列助词) ‌**和**‌ (列举不完全，暗示还有其他类似的东西)

6. ‌**理想 (りそう - risou):**‌ 理想

7. ‌は (wa):

   ‌ (主题助词) ‌

   （关于）...呢

   - *合起来 (あなたの夢や理想は):* ‌**你的梦想和理想呢**‌

8. ‌**だんだん (dandan):**‌ 渐渐，逐渐 (副词)

9. ‌近づいて (ちかづいて - chikazuite):

   - `近づく (ちかづく - chikazuku)`: 接近，靠近 (动词)
   - `いて (ite)`: (动词`近づく`的‌**て形**‌，连接补助动词`くる`)

10. ‌くる (kuru):

    ‌ 来 (动词原形，作为补助动词接在て形后)

    - *合起来 (近づいてくる):* ‌**（逐渐）靠近过来**‌ (`てくる` 表示变化的‌**开始、持续或向说话人方向靠近**‌的趋势，强调动态过程)

11. ‌**でしょう (deshou):**‌ (でしょう是です的推量形) ‌**将会...吧/大概会...吧**‌ (表示‌**推测、预判**‌，语气礼貌且带有一定的确信度)

‌**第二短句直译：**‌ 如果那样做的话，你的梦想和理想就会渐渐地靠近过来吧。

‌**全句直译：**‌
如果失败了，就再次挑战。如果那样做的话，你的梦想和理想就会渐渐地靠近过来吧。

‌**更自然的意译：**‌
如果失败了，就再挑战一次。只要你这样做，你的梦想和理想就会一步步向你靠近。

‌**文型分析 (句型分析)：**‌

‌**整体结构：**‌ 由两个条件句构成。第一个条件句（失敗したら...）描述行动准则，第二个条件句（そうすれば...）描述遵循这个准则带来的积极结果。

‌**第一短句分析：**‌

1. ‌条件从句：

   ```
   失敗したら
   ```

   - ‌**结构：**‌ `动词た形 + ら`
   - ‌**功能：**‌ 表示‌**假设条件**‌，“如果失败了...”。`たら` 强调条件的成立是动作发生的前提。

2. ‌主句：

   ```
   もう一度チャレンジする
   ```

   - ‌**结构：**‌ `副词 + 名词 + サ变动词`
   - ‌**功能：**‌ 描述在满足前述条件（失败）时应采取的行动：‌**再次挑战**‌。这是一个意志性的动作。

‌**第二短句分析：**‌

1. ‌条件从句：

   ```
   そうすれば
   ```

   - ‌**结构：**‌ `副词そう + 动词する的ば形`
   - ‌**功能：**‌ `そう`指代前一句描述的行为“失敗したら、もう一度チャレンジする”。`すれば` 表示‌**条件**‌，意思是“‌**如果（像前面说的）那样做的话**‌”。这个从句将前文整个行为作为本句结果发生的条件。

2. ‌主句：

   ```
   あなたの夢や理想はだんだん近づいてくるでしょう
   ```

   - ‌**主题：**‌ `あなたの夢や理想は` - 提出本句要谈论的主题：你的梦想和理想。

   - ‌谓语核心：

     ```
     近づいてくる
     ```

     - ‌**结构：**‌ `动词て形 + 补助动词くる`
     - ‌**功能：**‌ `近づく`（接近）表示状态变化。`てくる` 强调这种接近是一个‌**从无到有、逐渐发展、向目标（这里隐含的说话人/目标状态）靠近的动态过程**‌。结合副词`だんだん`（渐渐），更强化了渐进性。

   - ‌句末语气：

     ```
     でしょう
     ```

     - ‌**功能：**‌ 表示‌**推测、判断**‌。这里是对未来积极结果的预测，语气礼貌且带有鼓励性和一定的信心（虽然不完全确定，但可能性很高）。它使句子听起来更委婉、更积极。

‌**核心文型亮点：**‌

1. ‌**～たら、…：**‌ 表示假设条件，“如果...的话，就...”。是日常口语和书面语中非常常用的条件表达。
2. ‌**そうすれば、…：**‌ 表示承上启下的条件，“如果那样做的话，就...”。`そう`指代前文内容。
3. ‌**～てくる：**‌ 补助动词，表示动作或状态的变化‌**开始、持续或向说话人方向移动/发展**‌。这里表示目标“逐渐靠近”。
4. ‌**だんだん：**‌ 副词，表示“渐渐地”，描述变化的速度或进程。
5. ‌**～でしょう：**‌ 表示‌**推测、预判**‌（相当于“吧”、“大概会”），使语气委婉并带有积极预测的意味。

‌**总结：**‌
这个句子运用了两个紧密相连的条件句结构：

1. ‌**行动准则：**‌ `もし失敗したら、どうする？` -> `もう一度チャレンジする` (If failure happens, what to do? -> Challenge again)。
2. ‌**积极结果：**‌ `その行動をすれば、何が起こる？` -> `夢・理想がだんだん近づいてくる` (If you take that action, what happens? -> Dreams/Ideals will gradually come closer)。
   它通过清晰的逻辑和积极的预测（`でしょう`），有效地传达了“失败是成功之母，坚持不懈终将接近目标”的励志信息。`だんだん`和`てくる`的搭配生动地描绘了目标逐步实现的动态过程。
