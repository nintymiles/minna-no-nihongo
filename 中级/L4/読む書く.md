## 電話嫌い

電話嫌いと言われる人がいる。日本の作家、夏目漱石、アメリカの作家、マーク・トゥエイン、イギリスの H・G・ウェルズなども電話が嫌いだったようだ。電話を発明したグラハム・ベルと作家マーク・トゥエインの間にはおもしろいエピソードがある。

ベルは、彼が発明した電話をトゥエインにも利用してもらいたいと思ったが、トゥエインは電話が大嫌い。聞きたくもない音を聞かされ、話したくもないときに、話したくもない人と話させられる。失礼な機械である。

いくら断っても、しつこく勧めるべルに腹を立て、トゥエインはある文を新聞に発表した。「ハートフォードの市民には、いつものとおり、全員にクリスマスカードを送るが、ベルにだけは絶対に送らない」と。

それから数日後、トゥエインが病気になって、寝ているところに、親せきの人が亡くなったという知らせが届いた。トゥエインが葬式に出席できないのを残念がっていることを知ったベルは、すぐに、トゥエインの家と葬式が行われる教会を電話で接続しようと申し出た。トゥエインはなかなか「うん」と言わなかったが、結局、無料だというので、つないでもらうことにした。

早速、電話機がトゥエインのベッドのそばに取り付けられ、トゥエインは教会にいる出席者と話すことができ、電話の便利さを味わった。「電話の料金は払わせてください」とトゥエインが申し出ると、ベルは「料金は結構ですから、わたしにもクリスマスカードをください」と答えた。

(逓信総合博物館監修 『日本人とてれふぉん』「第5話 あちらの電話」NTT 出版より、一部を改変して掲載)

‌**总结全文翻译：**‌

有些人被称为讨厌电话的人。日本的作家夏目漱石、美国的作家马克·吐温、英国的H.G.威尔斯等人，似乎也讨厌电话。在发明电话的亚历山大·格拉汉姆·贝尔和作家马克·吐温之间，还有一段有趣的轶事。

‌**主要文型总结:**‌

1. ‌

   存在句 (Existence):

   ‌

   - `Nがいる/ある`: 表示人或事物的存在。例：`人がいる` (有人), `エピソードがある` (有轶事)。

2. ‌

   引用与称谓:

   ‌

   - `Nと言われる`: 表示"被称为N"。例：`電話嫌いと言われる` (被称为讨厌电话的人)。

3. ‌

   列举与添加:

   ‌

   - `N1、N2、N3など`: 表示举例，相当于"...等"。
   - `...なども`: 表示"连...也"，强调列举项的共同点。例：`...なども電話が嫌いだった` (...等也讨厌电话)。

4. ‌

   属性/状态:

   ‌

   - `Nが嫌いだ`: 表示"讨厌N"。
   - `形容詞/形容動詞 + ようだ`: 表示"看起来..."、"似乎..."（推测或委婉表达）。例：`嫌いだったようだ` (似乎曾经讨厌)。

5. ‌

   定语从句 (Modifying Clause):

   ‌

   - `Vた + N`: 过去式动词修饰名词，表示"做了...的N"。例：`電話を発明したグラハム・ベル` (发明了电话的贝尔)。
   - `N1とN2のN3`: 表示"N1和N2的N3"。例：`ベルとトゥエインの間` (贝尔和吐温之间)。

6. ‌

   场所/范围与主题:

   ‌

   - `N(場所/範囲)には`: 表示"在...之中/之间，有... (主题)"。例：`間に(は)エピソードがある` (在...之间有轶事)。

7. ‌

   并列:

   ‌

   - `N1とN2`: 表示"N1和N2"。例：`ベルとトゥエイン` (贝尔和吐温)。

1. ‌

   存在句 (Existence):

   ‌

   - `Nがいる/ある`: 表示人或事物的存在。例：`人がいる` (有人), `エピソードがある` (有轶事)。

2. ‌

   引用与称谓:

   ‌

   - `Nと言われる`: 表示"被称为N"。例：`電話嫌いと言われる` (被称为讨厌电话的人)。

3. ‌

   列举与添加:

   ‌

   - `N1、N2、N3など`: 表示举例，相当于"...等"。
   - `...なども`: 表示"连...也"，强调列举项的共同点。例：`...なども電話が嫌いだった` (...等也讨厌电话)。

4. ‌

   属性/状态:

   ‌

   - `Nが嫌いだ`: 表示"讨厌N"。
   - `形容詞/形容動詞 + ようだ`: 表示"看起来..."、"似乎..."（推测或委婉表达）。例：`嫌いだったようだ` (似乎曾经讨厌)。

5. ‌

   ‌

   - `Vた + N`: 过去式动词修饰名词，表示"做了...的N"。例：`電話を発明したグラハム・ベル` (发明了电话的贝尔)。

6. ‌

   场所/范围与主题:

   ‌

   - `N(場所/範囲)には`: 表示"在...之中/之间，有... (主题)"。例：`間に(は)エピソードがある` (在...之间有轶事)。

7. ‌

   并列:

   ‌

   - `N1とN2`: 表示"N1和N2"。例：`ベルとトゥエイン` (贝尔和吐温)。

1. ‌

   愿望表达 (Desire):

   ‌

   - `Vて + もらいたい`: 想让对方为我做某事。例：`利用してもらいたい` (想让...使用)。

2. ‌

   引用思考 (Quoted Thought):

   ‌

   - `...と思った`: 认为...，想过...。

3. ‌

   转折 (Contrast):

   ‌

   - `...(clause)が、...`: ...但是...。

4. ‌

   好恶表达 (Likes/Dislikes):

   ‌

   - `Nは + Objectが + Adj (好き/嫌い)`: 表示好恶。例：`トゥエインは電話が大嫌い` (吐温讨厌电话)。

5. ‌

   强烈否定愿望 (Strong Negation of Desire):

   ‌

   - `Vたく + も + ない`: "连...都不想..." (强调完全没有意愿)。例：`聞きたくもない`, `話したくもない`。

   ‌

   - 形式：`V未然形 + せられる/される`

7. ‌

   时间状语 (Time Adverbial):

   ‌

   - `V (Plain Form) + ときに`: 在...的时候。例：`話したくもないときに` (在根本不想说话的时候)。

   ‌

   ‌

7. ‌

   ‌

   - `いつものとおり` = 照例，和往常一样。

8. ‌

   ‌

   - `...にだけは` = 唯独给... (は强调限定和对比)。
   - `絶対に + Vない` = 绝对不...。
