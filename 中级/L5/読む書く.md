## 地図

​	地図Aは、オーストラリアの高校教師マッカーサーが 1979 年に作った「南北を逆にした世界地図」である。彼は日本留学中に、アメリカ人留学生のかいた世界地図を見て、びっくりした。その地図にはオーストラリアがなかったのだ。人間の目は、観察しようとする面の中央より少し上の方を自然に見るそうである。下の方は努力して見ようとしないと、見えないのだ。南半球にあるオーストラリアは、アメリカ人留学生の意識から忘れられていたのである。そこで、マッカーサーが自分で作ってみたのが地図Aである。

​	地図は普通、北を上にしてかかれる。では、なぜ北が上でなければならないのだろうか。これは地図に経緯度が使われるようになってからの 習慣であって、古い地図には南が上のものも多い。

​	北が上という常識は、実は北半球の國の人々が無意識に持っている差別の表れかもしれない。地図Bは南北を上下ではなく、左右に置いて、作ったものである。これなら、少なくとも、北半球の人々も南半球の人ダも文句は言わないだろう。しかし、アフリカと南アメリカはどうだろうか。「位置の平等」は難しい。

(森田喬 『神の眼 鳥の眼 蟻の眼　地図は自分さがしの夢空間』，毎日新聞社より、一部を改変して掲載)

‌**核心句型的分析与说明：**‌

1. ‌**[主题] は、[长定语从句] である。**‌

   - ‌**功能：**‌ ‌**对主题进行定义或说明。**‌ 这是典型的定义句或说明句结构。

2. ‌**[主语] が [时间] に [动词过去形] + [名词]**‌

   - ‌**功能：**‌ ‌**构成定语从句，修饰后面的名词。**‌ 描述这个名词是由谁在什么时间做了什么动作产生的。


     (澳大利亚的高中教师麦卡瑟在1979年制作的) - **这个定语从句修饰后面的名词短语

      

     ```
     「南北を逆にした世界地図」
     ```

     

     (南北反转的世界地图)。

     - `オーストラリアの高校教師マッカーサーが`：主语 (澳大利亚的高中教师麦卡瑟)
     - `1979 年に`：时间状语 (在1979年)
     - `作った`：动词过去形 (制作了)
     - ‌**整体含义：**‌ “澳大利亚高中教师麦卡瑟在1979年制作的”。

3. ‌**[宾语] を [动词过去形] + [名词]**‌

   - ‌本句应用：

     ```

     ```


      

     (世界地图)。

     - `南北を`：宾语 (把南北方向)

   - ‌**备注：**‌ 这个短语本身作为 `世界地図` 的修饰语，然后整个 `「南北を逆にした世界地図」` 又作为前面更长定语从句 `マッカーサーが...作った` 的修饰对象。形成了一个嵌套结构。

‌**整个句子的结构解析：**‌

1. ‌**主题提示：**‌ `地図Aは、` (关于地图A，)

2. ‌

   核心说明内容 (名词短语)：

   ‌

   - ‌**最外层定语从句 (描述制作者和时间)：**‌ `オーストラリアの高校教師マッカーサーが 1979 年に作った` (澳大利亚高中教师麦卡瑟在1979年制作的)


3. ‌**断定句尾：**‌ `である。` (就是。)

这是一个结构清晰的‌**定义说明句**‌，其核心功能是‌**说明地图A是什么**‌。句子的主干极其简单：`地図Aは ... 世界地図 である。` (地图A是...世界地图)。关键在于中间插入的‌**长定语从句**‌，它提供了关于这个“世界地图”的关键信息：

1. ‌**由谁制作的：**‌ 澳大利亚的高中教师麦卡瑟 (`オーストラリアの高校教師マッカーサーが`)
2. ‌**何时制作的：**‌ 1979年 (`1979 年に`)
3. ‌**有何特殊之处：**‌ 南北方向被反转 (`南北を逆にした`)

‌**核心句型的分析与说明：**‌

     - `日本留学中に`：时间状语 (在日本留学期间)
     - `アメリカ人留学生のかいた世界地図を`：宾语 (美国留学生画的世界地图)

2. ‌**[所有者/动作主体] の [动词过去形] + [名词]**‌

   - ‌**功能：**‌ ‌**构成定语从句，修饰后面的名词。**‌ 表示这个名词是由谁拥有的或者是谁做的动作的结果。在这里，「の」代替了格助词「が」，表示定语从句中动作的主体（画地图的人）。

   - ‌本句应用：‌ 

     ```
     アメリカ人留学生のかいた世界地図
     ```

      

     (美国留学生画的世界地图)

     - `アメリカ人留学生の`：定语从句的主语 (美国留学生) - 「の」相当于「が」(动作主体)。
     - `かいた`：动词过去形 (画了) - 表示完成的动作。
     - `世界地図`：核心名词 (世界地图)

   - ‌**整体含义：**‌ “由美国留学生画的”世界地图。这个定语从句作为宾语的一部分，说明了地图的来源和特征。

3. ‌**[て形动词] [表示感情的自动词]**‌

   - ‌**功能：**‌ ‌**表示前项动作是引发后项感情、感觉或生理现象的直接原因。**‌ 这是一种非常常见的表达因果关系的句型。

   - ‌

     本句应用：

     ‌

      

     ```

     ```

      

     (看了之后，大吃一惊了 / 因为看了，所以大吃一惊了)

     - `見て`：表示原因的て形动词 (因为看了)。
     - `びっくりした`：表示结果的情感动词 (大吃一惊了)。

   - ‌**整体含义：**‌ 清晰地表达了「見る」这个动作是导致「びっくりする」这个情感反应的直接原因。

‌**整个句子的结构解析：**‌

1. ‌**主题/主语：**‌ `彼は` (他)
2. ‌**时间状语：**‌ `日本留学中に` (在日本留学期间) - 说明主要动作发生的时间背景。
3. ‌**宾语 (带定语从句)：**‌ `アメリカ人留学生のかいた世界地図を` (美国留学生画的世界地图) - 宾语核心是「世界地図」，它被定语从句「アメリカ人留学生のかいた」修饰，说明地图的性质。
4. ‌**原因动作 (て形)：**‌ `見て` (看了之后 / 因为看了) - 主语执行的动作，是后续情感的直接诱因。
5. ‌**结果 (情感反应)：**‌ `びっくりした` (大吃一惊了) - 主语经历的情感状态变化，是句子的主要谓语，说明主题的状态或经历。

‌**总结：**‌

这个句子主要描述了一个事件：

- ‌**人物：**‌ 他 (`彼は`)
- ‌**时间：**‌ 在日本留学期间 (`日本留学中に`)
- ‌事件：
  1. 他‌**看到**‌了 (`見て`) 一张特定的地图。
  2. 这张地图是‌**由美国留学生画的**‌ (`アメリカ人留学生のかいた世界地図`)。(定语从句说明地图特征)
  3. 看到这张地图的‌**结果**‌是，他‌**大吃一惊**‌ (`びっくりした`)。(因果关系)

句型上，它结合了：

- ‌**时间状语 (`〜中に`)**‌ 设定背景。
- ‌**定语从句 (`所有者＋の＋动词过去形＋名词`)**‌ 修饰宾语，说明其来源。
- ‌**因果关系的て形结构 (`动词て形 + 情感动词`)**‌ 清晰地表达前因后果，这是理解句子核心意思的关键。句末的「びっくりした」是整句表达的最终结果和重点。

| ‌**の**‌             | の             | 形式名词              | (使句子名词化/解释说明)   | 将前面的小句「その地図にはオーストラリアがなかった」名词化，使其成为后续「だ」说明的对象。 |

| ‌**。**‌             |                | 标点                  | (句号)                    |                                                              |

‌**核心句型的分析与说明：**‌

1. ‌**[场所] には [主语] が いない / いなかった / ない / なかった。**‌

   - ‌功能：

     表示在某处不存在或没有某人/某物。

     ‌ 这是日语中表示“不存在”的经典句型。

     - `に`：表示存在的场所。
     - `は`：提示存在的地点为主题，并强调这个地点（常带有对比意味：“在这个地方是没有的”，暗示其他地方可能有）。
     - `が`：提示不存在的主体（人或物）作为主语。
     - `いない/いなかった/ない/なかった`：表示“不存在”的动词（いる用于生物，ある用于非生物）的否定形式。

   - ‌本句应用：

     - `その地図には`：存在的场所（那张地图上）+ `は`（强调这张地图）。
     - `オーストラリアが`：不存在的主体（澳大利亚）+ `が`（主语）。
     - `なかった`：非生物存在动词「ある」的过去否定简体形（不存在了/没有了）。

   - ‌**整体含义：**‌ “在那张地图上，澳大利亚不存在。” / “那张地图上没有澳大利亚。” `は`在这里加强了“在这张特定地图上”的强调和对其他地图可能不同的暗示。

2. ‌**[句子简体形] の だ / んです。**‌

   - ‌功能：

     用于句末，表示解释说明、强调事实、陈述理由或表达发现后的领悟语气。

     ‌ 这是日语中极其重要的一个表达方式。

     - `の`：形式名词，将前面的完整小句名词化，使其成为一个需要说明或确认的事实概念。
     - `だ / です`：断定助动词，对这个名词化的概念进行断定（简体是だ，敬体是です）。

   - ‌本句应用：

     ```
     その地図にはオーストラリアがなかった 
     ```

     +

     ```
     の
     ```

     +

     ```
     だ
     ```

     →

     ```
     オーストラリアがなかったのだ
     ```

     - 前面的小句「その地図にはオーストラリアがなかった」是一个完整的陈述句（那张地图上没有澳大利亚）。
     - `の`将其名词化，变成一个需要确认或强调的事实：“*那张地图上没有澳大利亚*这件事”。
     - `だ`对其进行断定说明：“是*那张地图上没有澳大利亚这件事*”。翻译时往往体现为对前面事实的强调、解释原因（这就是他吃惊的原因）或表达一种“原来如此”的领悟感。

   - ‌**整体含义：**‌ 这句话解释了前一句「彼はびっくりした」的原因（原来是因为那张地图上没有澳大利亚啊！）。它不仅仅陈述事实，更带有揭示原因、强调核心信息的语气。

   - ‌**注意：**‌ `のだ`（のです）在口语中常约音为`んだ`（んです）。

3. ‌**过去否定形：なかった**‌

   - ‌**构成：**‌ ある（存在 - 非生物） → ない（否定形：不存在） → なかった（过去否定形：过去不存在/当时没有）
   - ‌**功能：**‌ 表示在过去的某个时间点或某段时间内，某物不存在或不处于某种状态。
   - ‌**本句应用：**‌ 表示在“他看地图”的那个过去时间点，澳大利亚在地图上是“不存在”的。

‌**整个句子的结构解析：**‌

1. ‌**地点主题：**‌ `その地図には` (在那张地图上) - `は`强调了这张地图的特殊性（暗示其他地图可能有）。
2. ‌**不存在的主体：**‌ `オーストラリアが` (澳大利亚) - 作为「なかった」的主语。
3. ‌**谓语 (过去否定)：**‌ `なかった` (没有了 / 不存在了) - 描述主语在过去的状态。
4. ‌**解释说明语气：**‌ `の だ` - 将前面的陈述「那张地图上没有澳大利亚」作为一个既定事实或原因进行强调和确认。

‌**总结：**‌

这个句子揭示了前文「彼はびっくりした」(他大吃一惊)的原因：

- ‌**核心事实：**‌ `その地図にはオーストラリアがなかった` (那张地图上没有澳大利亚)。
- ‌**表达重点：**‌ 使用「のだ」强调了这一事实，使其带有解释原因（所以他吃惊）、确认事实或表达发现的语气。
- ‌**语境理解：**‌ 承接上文，这张地图是美国留学生画的，上面竟然缺失了整个澳大利亚，这显然不符合常理或预期（通常世界地图会包括澳大利亚），因此让他感到惊讶。

句型上，它结合了：

- ‌**存在否定句 (`[场所]には [物]が ない/なかった`)**‌ 表示某处缺少某物。
- ‌**解释说明句式 (`〜のだ`)**‌ 对前述事实进行强调和解释，赋予句子更强的陈述理由和揭示真相的语气。

   - ‌本句应用：

     - `見ようとしない`：不想看 / 不打算看 / 拒绝尝试去看。这里指主观上“没有做出努力去看的动作行为”。
     - `努力して`：副词短语，“努力地”。修饰「見ようとしない」，说明这种“不看”不是随意的，而是指“不付出努力去尝试看”。

3. ‌**[副词短语] + [动词意志形] と しない**‌

   - ‌功能：

     副词修饰整个“不打算做”的动作，说明方式。

     - `努力して`：副词短语，“努力地”、“使劲地”。
     - `見ようとしない`：“不打算看”、“不想看”。

   - ‌**本句应用：**‌ `努力して見ようとしない` 意思是“不努力尝试去看”。副词「努力して」强调了“看”这个动作需要付出努力，而主语拒绝了付出这种努力。

4. ‌**可能动词的否定: 見えない**‌

   - ‌功能：

     表示“不能看见”、“无法看见”。

     ‌ 是「見える」(能看见) 的否定形式。

     - `見える`：自动词/可能动词，表示视觉上的能力或可能性。
     - `見えない`：其否定形。

   - ‌**本句应用：**‌ 作为主句的结果，表示在「努力して見ようとしない」这个条件下，视觉上的结果就是「見えない」(无法看见)。

‌**整个句子的结构解析：**‌

1. ‌**主题：**‌ `下の方は` (下方的区域) - 句子的主题，也是描述的对象。

2. ‌条件从句：

   ```
   努力して見ようとしないと
   ```

   (如果不努力尝试去看的话) - 提出一个否定性的条件。

   - `努力して`：方式副词 (努力地)。
   - `見ようとしない`：核心动作 (不打算看)。
   - `と`：条件接续助词 (如果...的话)。

3. ‌**结果主句：**‌ `見えない` (看不见) - 表示在上述条件下产生的结果。

4. ‌**解释说明：**‌ `のだ` (是...的 / 因为...) - 赋予整个句子解释说明的语气，强调这是一种客观事实或原因。

‌**总结：**‌

这个句子解释了为什么人的视线不容易注意到下方区域：

- ‌**对象：**‌ 下方的区域 (`下の方は`)。
- ‌**关键条件：**‌ ‌**不做出努力去看的动作**‌ (`努力して見ようとしないと`)。
- ‌**结果：**‌ ‌**就看不见**‌ (`見えない`)。
- ‌**语气：**‌ 用 `のだ` 强调了这是一种需要解释的现象或客观事实。

‌**与前句的联系：**‌
这个句子是承接前一句「人間の目は...中央より少し上の方を自然に見るそうである」（据说人的眼睛会自然地看向中心偏上位置）的。它解释了这种现象的一个后果：因为视线自然地落在上方区域，所以对于‌**下方区域 (`下の方`)**‌，如果不有意识地付出‌**努力 (`努力して`)**‌ 主动去尝试看 (`見ようとしない`)，就‌**无法看见 (`見えない`)**‌。这强调了观察下方区域需要额外的、主动的注意力投入。

‌**核心句型的分析与说明：**‌

1. ‌**[主题] は ... [被动持续过去形] のである。**‌

   - ‌功能：

     描述一个过去持续存在的状态或事实，并用「のである」进行解释、说明或强调结论。

     ‌

     - `は`：提示主题 (南半球にあるオーストラリア)。
     - `から`：表示动作的起点/来源/脱离点 (アメリカ人留学生の意識から)。
     - `忘られていた`：被动（被遗忘） + 持续体（...着） + 过去时（...了） → ‌**“曾被（长久）遗忘着”**‌。
     - `のである`：解释说明助动词结构，强调这是得出的结论或客观事实。

   - ‌**本句应用：**‌ 解释澳大利亚（在地理认知上）曾经被美国留学生所忽视的这一事实。

2. ‌**そこで、[主语] が [方式で] [动词てみた] のが [宾语] である。**‌

   - ‌功能：

     承接前文原因，说明结果。强调某人亲自尝试做了某事，而做出来的结果就是某物。

     - `そこで`：接续词，表示因果关系或顺承关系（因此、于是）。
     - `が`（第一个）：提示动作执行者（マッカーサー）。
     - `で`：格助词，表示方式（自分で → 亲自）。
     - `动词てみた`：尝试做了某事（作ってみた → 试着制作了）。
     - `のが`：「の」使前面的动作名词化（マッカーサーが自分で作ってみたの），「が」提示这个名词化短语是主语。
     - `宾语 + である`：谓语部分，对主语进行断定说明（地図Aである → 就是地图A）。

   - ‌**本句应用：**‌ 说明作为上述（被忽视）情况的结果，麦克阿瑟亲自尝试制作的东西就是地图A。

3. ‌**被动语态: [动作对象] は [动作来源] から [动词被动形]。**‌

   - ‌功能：

     描述动作对象承受来自动作来源的动作。动作来源用「に」或「から」表示。

     ‌

     - 动作对象：`オーストラリアは` (主题)。
     - 动作来源：`アメリカ人留学生の意識から` (认知来源)。
     - 动词被动形：`忘られていた` (曾被遗忘着)。

   - ‌**本句应用：**‌ 澳大利亚（对象）被从美国留学生的意识（来源）中遗忘了。

4. ‌**尝试态: [动词て形] + みる / みた。**‌

   - ‌功能：

     表示尝试性地做某事，“试着做...”、“做做看”。

     ‌

     - `作って`：动词「作る」的て形。
     - `みた`：补助动词「みる」的过去形。

   - ‌**本句应用：**‌ `作ってみた` → 试着制作了。表明麦克阿瑟是动手尝试制作地图的。

‌**整个句子的结构解析与逻辑关系：**‌

1. ‌**第一分句 (事实陈述与解释):**‌

   - ‌**主题:**‌ `南半球にあるオーストラリアは` (位于南半球的澳大利亚) - 描述的对象。
   - ‌**谓语核心:**‌ `アメリカ人留学生の意識から忘られていた` (从美国留学生的意识中被遗忘了) - 描述一种过去持续存在的被动状态。
   - ‌**解释说明:**‌ `のである` (就是这样) - 强调这是一个需要说明或被揭示的事实。
   - ‌**结论:**‌ 澳大利亚（因其地理位置）在美国留学生的认知中长期缺席。

2. ‌**第二分句 (因果承接与结果):**‌

   - ‌**连接:**‌ `そこで` (因此) - 表明后句是前句所述情况导致的结果。

   - ‌强调动作:

     ```
     マッカーサーが自分で作ってみたの 
     ```

     (麦克阿瑟自己试着制作出来的东西) - 名词化短语作主语，强调“麦克阿瑟亲自尝试制作”这个行为及其产物。

     - `自分で`：亲自地，突显主动性。
     - `作ってみた`：尝试制作，强调探索性或初次尝试。

   - ‌**谓语断定:**‌ `が地図Aである` (就是地图A) - 对主语进行明确的界定和断定。

‌**总结：**‌

这个句子由两个逻辑紧密相连的分句构成：

1. ‌**揭示问题：**‌ 指出位于南半球的澳大利亚在美国留学生的地理意识中被长期忽视 (`オーストラリアは...忘られていたのである`)。「のである」加强了陈述的客观性和结论性。
2. ‌**说明对策与结果：**‌ 因此 (`そこで`)，麦克阿瑟采取了行动——他亲自尝试 (`自分で作ってみた`) 制作地图，而他所制作出来的成果 (`...のが`)，被明确指出就是地图A (`地図Aである`)。

‌**关键点：**‌

- ‌**被动与遗忘：**‌ 澳大利亚是被遗忘的对象，遗忘来源于美国留学生的认知（意識から）。被动语态和「忘られていた」的持续过去形式共同塑造了一种“长久被忽视”的状态。
- ‌**主动尝试：**‌ 麦克阿瑟是积极的行动者（が），他通过亲自（で）尝试（てみる）来应对上述问题。
- ‌**名词化与断定：**‌ 第二句的核心是将麦克阿瑟的尝试制作行为及其结果名词化（...のが），然后用「...である」明确断定其身份（地图A）。这种结构使得“麦克阿瑟制作的成果”成为了句子的焦点信息。
- ‌**のである vs である：**‌ 第一句的「のである」解释说明一个事实/状态；第二句末尾的「である」是对主语成分的简单断定。

     - `北半球の國の人々が無意識に持っている差別` → “北半球国家的人们无意识中持有的歧视”。（从句 `...持っている` 修饰名词 `差別`）。
- `差別の表れ` → “歧视的表现/体现”。（名词 `差別` 修饰名词 `表れ`）。

‌**整个句子的结构解析：**‌

1. ‌**主题:**‌ `北が上という常識は` (以北为上这一常识) - 提出要讨论的对象。
2. ‌**推测性谓语核心:**‌ `...かもしれない` (也许是...) - 对主题的本质提出推测。
3. ‌**推测内容 (名词短语):**‌ `差別の表れ` (歧视的体现) - 主题被推测是什么。
4. ‌**修饰推测内容 (定语从句):**‌ `北半球の國の人々が無意識に持っている` (北半球国家的人们无意识中持有的) - 具体说明这是‌**谁**‌持有、‌**如何**‌持有的歧视。

‌**总结：**‌

这个句子对一个普遍的地图绘制规则（北在上）提出了社会学/心理学层面的批判性解读：

- ‌**批判对象：**‌ “北为上”这一常识 (`北が上という常識`)。
- ‌**推测本质：**‌ 这是一种‌**歧视的体现**‌ (`差別の表れかもしれない`)。
- ‌**持有主体：**‌ ‌**北半球国家的人们**‌ (`北半球の國の人々が`)。
- ‌**持有状态：**‌ ‌**无意识中**‌ (`無意識に`) ‌**持续地**‌ (`持っている`)。

作者认为，将北方置于地图顶端的做法 (`北が上`)，可能 (`かもしれない`) 反映了 (`表れ`) 位于地球上半部分 (`北半球`) 发达国家 (`國の人々`) 的人们的一种未被察觉 (`無意識`) 的优越感或中心视角 (`差別`)。这是一种带有思辨和社会批判色彩的观点陈述。
