## 2万5千人の個人情報が流出

**MNK社の力ード会員**

　通信販売会社のMNK社は8日、同社発行のMN力ードに加入する会員2万5034人分のカード番号·暗証番号など個人情報が流出した、と発表した。このほかにも約8000人分の個人情報が流出した可能性もあり、警察などと協力して被害の実態と原因を調べている。

　同社によると、流出したのは氏名、カード番号、暗証番号のほか預金口座番号、住所、電話番号、性別、職業、生年月日の9項目に及ぶ。3月上旬に会員から 「身に覚えのない会社から未払い金の請求書が送られてきた」と相談の電話があり、調査したことでデータ流出が判明した。現在での約1か月間で同様の苦情や相談が50件以上寄せられ、そのうち3人は既に請求に応じて支払いを済ませている。

　同社は「情報管理を厳しくしていたにもかかわらず、今回の事態が起きたことは遺憾。コンピューターシステムのトラブルによるものか、内部ないし外部からの情報引き出しによってか、データ流失が起きたものとみられる」としている。システム面での調査を進めながら、警察にも協力を求めて、情報流出と被害の関連を調べている。

　また、とりあえず被害を受けた会員におわびの書面を送るとともに、会員力ードの更新などの対策を早急に講ずるとしている。

　被害者の一人は「インターネッ卜の有料サイ卜から請求書をダイレク卜メールで受け取った。普段よくインターネットを使って支払いもしているので、おかしいと思いながらも、請求金額1万2千円を近くの銀行から指定された口座に振り込んだ」という。しかし、だまされたのではないかと不審に思ってそのご、振込口座名と番号を調べたところ、既に口座は閉じられていたと言っている。

### S1

通信販売会社のMNK社は8日、同社発行のMN力ードに加入する会員2万5034人分のカード番号·暗証番号など個人情報が流出した、と発表した。翻译 文法

翻译：
‌**邮购公司MNK于8日公布，该公司发行的MN卡会员中，共25034人的卡号、密码等个人信息遭到泄露。**‌

（注：原文“MN力ード”应为“MNカード”的笔误，此处译为“MN卡”。）

------

‌**文法解析：**‌

- ‌**主句结构**‌
  `通信販売会社のMNK社は … と発表した。`
  整体是“MNK公司公布了……”，`と` 提示引述内容，后面接 `発表した`（公布、发表了）。

- ‌**主语**‌
  `通信販売会社のMNK社は`
  “邮购公司的MNK公司”，`の` 表示所属，“MNK社”是主题。

- ‌**时间状语**‌
  `8日`
  表示“8日”，这里省略了月份，按上下文多半指当月8日。

- ‌**引述内容（"……と"的部分）**‌
  `同社発行のMNカードに加入する会員2万5034人分のカード番号·暗証番号など個人情報が流出した`
  这是一个完整的句子，用于说明发生了什么。

  分解：

  - `同社発行のMNカードに加入する会員`
    “加入了该公司发行的MN卡的会员”，`同社`=该公司，`発行`=发行，`加入する`=加入/办理，这个整体修饰后面的“会员”。
  - `2万5034人分の`
    “25034人份的”，`人分` 表示按人数计算的数量份额，即“这么多人的……”。
  - `カード番号·暗証番号など個人情報`
    “卡号、密码等个人信息”，`·` 表示并列，“など”表示“等等”。
  - `が流出した`
    主语为上述“个人信息”，谓语句子，`流出する` 的过去式，意为“泄露了、流出”。`が` 提示主语。

- ‌**整体逻辑**‌
  该新闻句式是“【谁】在【何时】公布了【什么事实】”。其中事实部分是“持有MN卡的25034名会员的卡号密码等信息泄露了”，嵌入在 `～と発表した` 的引用结构中。

### S5

現在での約1か月間で同様の苦情や相談が50件以上寄せられ、そのうち3人は既に請求に応じて支払いを済ませている。翻译 文法

这句话的原文是：

‌**現在での約1か月間で同様の苦情や相談が50件以上寄せられ、そのうち3人は既に請求に応じて支払いを済ませている。**‌

------

中文翻译

在至今大约一个月的时间里，类似的投诉和咨询已收到50件以上，其中3人已经按照要求付了款。

（更自然一点：近一个月左右，已经收到了50多件同类投诉与咨询，其中有3人已经应对方的要求支付了款项。）

------

文法重点解析

‌**1. 現在での約1か月間で**‌

- 意思是“在至今的大约一个月间”。严格文法上通常说「現在までの約1か月間で」或「現在から約1か月の間で」，这里用了「現在での」比较口语，可以看作「現在で」＋「の」来修饰期间。
- 「で」表示动作发生的时间范围。

‌**2. 同様の苦情や相談が**‌

- 「同様の」＝“同样的、类似的”。
- 「苦情」＝“投诉”，「相談」＝“咨询”，用「や」并列。
- 「が」是主语标记。

‌**3. 寄せられ**‌

- 「寄せる」的被动态「寄せられる」的连用形，用来中顿。
- 「寄せられ」相当于「寄せられて」，意思是“被寄来”，中文自然说成“收到”。

‌**4. 50件以上**‌

- “50件以上”，表示数量超过50件。

‌**5. そのうち3人は**‌

- 「そのうち」＝“其中”。
- 「3人は」表示“有3人”，此处用「は」提示主题。

‌**6. 既に**‌

- 副词，“已经”。

‌**7. 請求に応じて**‌

- 「請求」＝“请求、要求（多指催款、索赔等）”。
- 「応じて」是「応じる」的て形，“响应、答应”的意思。
- 整体表示“应要求/响应请求”。

‌**8. 支払いを済ませている**‌

- 「支払い」＝“支付”。
- 「済ませる」是他动词，“完成、做完”。
- 「済ませている」是ている形，表示动作完成后状态的持续，即“已经付清了”。

------

句构小记

整个句子是「～寄せられ、～済ませている」的结构，前半用被动（投诉被寄来），后半用主动（三人完成支付），中间用连用形中顿来连接，这是日语句子中典型的并列叙述方式。

### S6

‌**同社は「情報管理を厳しくしていたにもかかわらず、今回の事態が起きたことは遺憾。コンピューターシステムのトラブルによるものか、内部ないし外部からの情報引き出しによってか、データ流失が起きたものとみられる」としている。**‌

------

中文翻译

该公司表示：“尽管对信息管理一直很严格，但发生此次事态仍令人遗憾。目前可认为发生了数据外流，其原因可能是电脑系统故障所致，也可能是由于来自内部或外部的信息窃取所造成。”

------

文法重点解析

1. 同社は〜としている

- 「同社」＝“该公司”（新闻报道中第二次提及时常用「同社」代替公司名）。
- 「〜としている」是「〜とする」的ている形，用于引用、传达某方的主张或看法，相当于“表示……”“称……”。

2. 情報管理を厳しくしていたにもかかわらず

- 「情報管理を厳しくしていた」＝“一直严格进行信息管理”。「厳しく」是形容词「厳しい」的连用形作副词用。
- 「〜にもかかわらず」＝“尽管……却……”“虽然……但是……”，表示逆接，后项是与前项预期相反的结果。

3. 事態が起きたことは遺憾

- 「事態」＝“事态、情况”。
- 「起きた」是「起きる」的过去形，“发生”。
- 「〜ことは遺憾」＝“……这件事是令人遗憾的”。「遺憾」是形容动词，在这里作名词性谓语，省略了「だ/です」，因为这是引语内部，可以省略。

4. 〜によるものか

- 「AによるB」＝“由A引起的B、因A造成的B”。
- 「〜もの」在这里代指“原因、情况”，即“是由……造成的”。
- 「か」是并列助词，与后面的「か」一起表示“是……还是……”，列举两种可能性。这里第一个「か」前没有「もの」，相当于「〜によるものなのか」的省略表达。

5. 内部ないし外部からの情報引き出しによってか

- 「内部ないし外部」＝“内部或外部”。「ないし」是书面语，“或者、乃至”。
- 「情報引き出し」＝“信息窃取、提取信息”。“引き出し”在这里读作「ひきだし」，意为“提取、获取”，在上下文中带有“未经授权的获取”的语感。
- 「〜によって」＝“通过……、由于……”，这里与前面的「〜による」对应，表示原因、手段。

6. データ流失が起きたものとみられる

- 「データ流失」＝“数据外流、数据流失”。
- 「起きた」同上，“发生”。
- 「〜ものとみられる」＝“可认为是……、据推测是……”。「みられる」是「見る」的被动可能态，表示自然得出的判断，常用于新闻报道中表达“据观察/推测”的语气。前面的「もの」是形式名词，指代前文所述的“数据外流”这件事。

------

整体句构总结

整个句子结构可以这样拆解：

```
同社は [ 〜は遺憾。 〜ものとみられる。 ] としている。
```

引语内部又分两句：

1. 「情報管理を厳しくしていたにもかかわらず、今回の事態が起きたことは遺憾。」
   （尽管……，但发生此事令人遗憾。）
2. 「（Aによるものか、Bによってか、）データ流失が起きたものとみられる。」
   （可认为发生了数据外流，是A还是B导致的。）

其中 A 和 B 这两条可能原因以「〜か、〜か」的形式并列，属于插入式的补充说明。

### S7

**システム面での調査を進めながら、警察にも協力を求めて、情報流出と被害の関連を調べている。**‌

------

中文翻译

在推进系统层面调查的同时，也在向警方寻求协助，调查信息外流与受害之间的关联。

------

文法重点解析

1. システム面での調査

- 「システム面」＝“系统层面、系统方面”。
- 「面」读作「めん」，表示“方面、层面”的意思。
- 「での」是「で」＋「の」的组合。「AでのB」相当于“在A方面的B、在A层面上的B”。这里的「で」表示领域、方面，“在系统方面”。

2. 進めながら

- 「進める」是他动词，“推进、进行”。
- 「〜ながら」接在动词连用形（ます形去ます）后面，表示“一边……一边……”或“在……的同时”。
- 这里「調査を進めながら」＝“一边推进调查，一边……”，表示两个动作同时并行。

3. 警察にも協力を求めて

- 「警察に」＝“向警方”。
- 「も」是提示助词，“也”。“警察にも”带有“不只是在系统方面调查，还向警方”的语感，暗示调查从多个渠道同时展开。
- 「協力を求める」＝“寻求协助、请求配合”。「求める」读作「もとめる」。
- 「求めて」是「求める」的て形，在这里用来连接后面的句子，表示动作的先后或手段。

4. 情報流出と被害の関連

- 「情報流出」＝“信息外流”。
- 「と」是并列助词，“和、与”。
- 「被害」＝“受害、损失”。
- 「関連」＝“关联、关系”。
- 整体意思是“信息外流与受害之间的关联性”。

5. 調べている

- 「調べる」是他动词，“调查”。
- 「ている」形在这里表示动作正在进行中，即“正在调查”。

------

整体句构总结

整个句子可以这样拆解：

```
[ システム面での調査を進めながら ]、
[ 警察にも協力を求めて ]、
[ 情報流出と被害の関連を調べている ]。
```

动作的主语是同一主体（该公司）。三个动作的关系是：

1. ‌**進めながら**‌（一边推进系统层面的调查）
2. ‌**求めて**‌（一边向警方寻求协助）
3. ‌**調べている**‌（正在调查关联性）

前两个动作用ながら和て形表示并行或手段，最后的「調べている」是句子的主干谓语。

这句话体现了日语中通过连用形和て形将多个动作自然串联成一句的特点，翻译成中文时需要适当补充“一边……一边……”来体现这种并行关系。

------

和前面那句公司声明相比，这句话本身是叙述文，而非引语，但同样出自新闻报道的语气，客观、简洁。如果有整个段落的句子需要连贯拆解，也可以一起发过来。

### S8

‌**また、とりあえず被害を受けた会員におわびの書面を送るとともに、会員カードの更新などの対策を早急に講ずるとしている。**‌

------

中文翻译

此外，该公司还表示，将先向受害会员发送致歉信函，同时也会尽快采取更新会员卡等对策。

（更自然一点：此外，公司还称，会暂时先向受到损失的会员寄送致歉函，并同时尽快实施包括更换会员卡在内的应对措施。）

------

文法重点解析

1. また

- 接续词，“此外、另外、还有”。在新闻中用于补充同一主体的另一项声明或措施。

2. とりあえず

- 副词，“暂且、先、目前先”。有一种“先采取紧急的一步，后续可能还有进一步措施”的语感。这里指的是先发致歉信。

3. 被害を受けた会員に

- 「被害を受けた」是连体修饰语，修饰「会員」。“遭受了损失的/受害的”。
- 「〜に」表示对象，“向……”。即“向受害的会员”。

4. おわびの書面

- 「おわび」＝「お詫び」，“道歉、致歉”。「お」是美化语接头词。
- 「書面」＝“书面文件、信函”。
- 「おわびの書面」＝“致歉信、道歉函”。

5. 送るとともに

- 「送る」＝“发送、邮寄”。
- 「Aとともに、B」＝“在A的同时（还）B”、“与A一道B”。这里的「とともに」接在动词终止形后，表示两个事项同时进行，或附带、并列关系，语气比「ながら」更正式，常用于书面、演说。

6. 会員カードの更新などの対策

- 原文是「会員力ード」，很明显是打字错误，正确应为「会員カード」（会员卡）。
- 「更新」＝“更新、更换”。
- 「〜など」＝“……等”，例举。
- 「対策」＝“对策、措施”。

7. 早急に講ずる

- 「早急」读作「そうきゅう」或「さっきゅう」，意思是“尽快、紧急”。
- 「講ずる」是他动词，“采取（措施）、谋求”。常用搭配是「対策を講ずる」（采取对策）。「講ずる」是サ变动词，也是「講じる」的文语或郑重说法。

8. としている

- 和上一句一样，「〜としている」表示“该公司表示……”，是新闻体中引述公司声明时的常用表达。

------

整体句构总结

整个句子可以这样拆解：

```
また、
[ とりあえず被害を受けた会員におわびの書面を送る ] とともに、
[ 会員カードの更新などの対策を早急に講ずる ] としている。
```

主干结构是：

```
A とともに B としている。
```

“表示既要做A，同时也要做B。”

其中：

- A = とりあえず 被害を受けた会員に おわびの書面を送る
- B = 会員カードの更新などの対策を 早急に講ずる

这两个动作是并列关系，都以「としている」收束，表示这些都是该公司表明将要采取的行动。

### S9

**被害者の一人は「インターネットの有料サイトから請求書をダイレクトメールで受け取った。普段よくインターネットを使って支払いもしているので、おかしいと思いながらも、請求金額1万2千円を近くの銀行から指定された口座に振り込んだ」という。**‌

------

中文翻译

其中一位受害者称：“我通过直邮收到了一份来自互联网付费网站的账单。因为平时经常使用网络进行支付，所以虽然觉得有点不对劲，但还是从附近的银行把1万2千日元的请款金额汇入了指定的账户。”

------

文法重点解析

1. 被害者の一人は〜という

- 「被害者の一人」＝“受害者之一、其中一位受害者”。
- 「〜という」＝“说……、称……”，用于直接引用某人的话。在新闻中常用来引述当事人的陈述。

2. インターネットの有料サイトから

- 「有料サイト」＝“付费网站”。
- 「〜から」＝“从……”，这里表示请求书的来源。“从付费网站来的账单”。

3. 請求書をダイレクトメールで受け取った

- 「請求書」＝“账单、请款单”。
- 「ダイレクトメール」（direct mail）＝“直邮广告/邮件”，简称DM。句中是说以直邮形式收到的账单。
- 「で」表示手段、方式，“通过直邮”。
- 「受け取った」是「受け取る」的过去形，“收到了”。

4. 普段よくインターネットを使って支払いもしているので

- 「普段」＝“平时”。
- 「よく」＝“经常”。
- 「インターネットを使って」＝“使用网络”。「使って」是「使う」的て形，表手段。
- 「支払いもしている」＝“也进行支付/也付款”。这里的「も」是“也”，暗示不只是使用网络做其他事，连付款也用网络。
- 「〜ので」＝“因为……所以……”，表示原因理由，语气比「から」稍微客观、柔和。

5. おかしいと思いながらも

- 「おかしい」＝“奇怪、不对劲”。
- 「〜と思い」＝“觉得……、认为……”。「思い」是「思う」的连用形。
- 「〜ながら」＝“一边……一边……”→“虽然……但是……”。这里表示“虽然觉得奇怪”，用逆接。
- 「も」加在「ながら」后面，加强逆接语气，“尽管……但还是……”。

6. 請求金額1万2千円を

- 「請求金額」＝“请款金额、账单金额”。
- 「1万2千円」＝12000日元。「1万2千円」是「一万二千円」的省略性数字表记。
- 「を」是宾语标记。

7. 近くの銀行から指定された口座に振り込んだ

- 「近くの銀行」＝“附近的银行”。
- 「〜から」＝“从……”（表示场所的起点，即从银行汇款）。
- 「指定された口座」＝“被指定的账户/指定账户”。「指定された」是「指定する」的被动态过去形，作连体修饰语。
- 「〜に」＝“向……、往……”（汇入的目标，指定账户）。
- 「振り込んだ」是「振り込む」的过去形，“汇款、转账（到账户里）”。

------

整体句构总结

整个句子：

```
被害者の一人は    [   インターネットの有料サイトから請求書をダイレクトメールで受け取った。
    普段よくインターネットを使って支払いもしているので、
    おかしいと思いながらも、
    請求金額1万2千円を近くの銀行から指定された口座に振り込んだ    ]    という。
```

引号内是受害者陈述的两个句子，实际可视为一个长句：

```
[ 受け取った ] 再加上  [ ので、〜ながらも、〜振り込んだ ]
```

因果关系：

- 因为平时经常用网络付款（‌**ので**‌）
- 虽然觉得有点奇怪（‌**ながらも**‌）
- 还是把钱汇了（‌**振り込んだ**‌）

------

补充说明：几个容易看错的假名

这句话里「インターネッ卜」和「ダイレク卜メール」中的「卜」应该是「ト」（片假名的 to），是典型的字形识别或手打易混。正确分别为：

- インターネッ‌**ト**‌
- ダイレク‌**ト**‌メール

### S10

原文是：

‌**しかし、だまされたのではないかと不審に思ってそのご、振込口座名と番号を調べたところ、既に口座は閉じられていたと言っている。**‌

------

中文翻译

但（该受害者）说，因为觉得可疑，怀疑自己是不是被骗了，之后去查了转账账户名和账号，结果发现账户已经被注销了。

（更自然一点：但此人表示，当时觉得事有蹊跷，怀疑自己是否上当受骗，于是去查了汇款的账户名和账号，一查才发现该账户早已被关闭了。）

------

文法重点解析

1. しかし

- 接续词，“但是、然而”。表示与前面陈述的内容形成转折。

2. だまされたのではないか

- 「だまされた」是「だます」（骗）的被动态过去形，“被骗了”。
- 「〜のではないか」＝“是不是……呢、难道不是……吗”，表示推测性的疑问。这里整体意思是“是不是被骗了”。

3. 〜と不審に思って

- 「〜と思う」＝“觉得……、想……”。这里引号前面的「と」是内容标记。
- 「不審（ふしん）」是形容动词，“可疑、疑惑”。
- 「不審に思う」＝“觉得可疑、感到疑惑”。「不審に」是形容动词的连用形作副词修饰「思う」。
- 整体「だまされたのではないかと不審に思って」＝“怀疑是不是被骗了，觉得可疑”。

4. そのご

- 写为「その後」，“之后、此后、然后”。
- 这里省略了主语，是指“觉得可疑”这个动作之后。

5. 振込口座名と番号を調べたところ

- 「振込口座名（ふりこみこうざめい）」＝“转账账户名”。
- 「番号」＝“账号、号码”。
- 「調べた」是「調べる」的过去形，“查了、调查了”。
- 「〜たところ」是个非常重要的语法点：接在动词过去形后，表示“做了某事后，结果发现……”，带有“意外发现”或“契机”的语感。这里意思是“一查之下发现……”。

6. 既に口座は閉じられていた

- 「既に（すでに）」＝“已经”。
- 「口座（こうざ）」＝“账户”。
- 「閉じられていた」是「閉じる」（关闭）的被动态「閉じられる」的ていた形。被动态表示账户“被关闭”，ていた表示“关闭”这个状态的持续或过去的完成，即“已经被关闭了”。

7. と言っている

- 「〜と言っている」＝“说……、表示……”。这里的「ている」表示引用内容在当下的有效性，强调“（该受害者）是这样说的”。如果与前面一句那个「という」相比，「という」偏客观引用，而「と言っている」更强调当事人的主张本身。

------

整体句构总结

整个句子可以分成几个部分：

```
しかし、
[ だまされたのではないかと不審に思って ]、
そのご、
[ 振込口座名と番号を調べたところ ]、
[ 既に口座は閉じられていた ] と言っている。
```

‌**各个部分的逻辑关系是：**‌

- ‌**不審に思って**‌ → 原因/契机（因为觉得可疑）
- ‌**そのご〜調べた**‌ → 随之采取的行动（之后去查了）
- ‌**〜たところ**‌ → 该行动带来的意外发现（一查才发现）
- ‌**既に口座は閉じられていた**‌ → 发现的具体内容（账户已被关闭）

这三种接续（て形表缘由、たところ表契机与意外发现、ていた表结果状态）是日语叙事中很典型的组合，让事件的前因后果非常清楚，节奏自然。
